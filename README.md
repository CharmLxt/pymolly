pymolly (или просто Молли) — это дружелюбный баг-репортер для Python. Библиотека перехватывает ошибки и объясняет их простым языком, подсказывая возможные причины и способы исправления. Вместо стандартного стектрейса на тридцать строк Молли выводит короткое понятное сообщение. Библиотека работает только через import, никаких консольных команд нет.



В версии 10.5.0 добавлен пятый модуль — monoMolly. Это специализированный анализатор, созданный специально для проекта Monogrammer (удаленное управление ПК). Он перехватывает сетевые ошибки (ConnectionRefusedError, TimeoutError, socket.gaierror, ssl.SSLError) и выдает не просто сухие факты, а конкретные советы по отладке. Например, если соединение отклонено, monoMolly подскажет: «Убедитесь, что на ПК друга запущен Агент, и проверьте, не блокирует ли брандмауэр порт 8080». Если случился таймаут, модуль посоветует запустить ndVpi для проверки стабильности сети или снизить качество видео-потока. Использовать его можно как контекстный менеджер (with monoMolly():) или как декоратор (@monoMolly.watch). Обычные ошибки он передает базовой Молли.



Остальные четыре модуля остались прежними. Molly — базовый уровень: ловит исключение и объясняет его. Работает как контекстный менеджер, как декоратор, вручную через try/except или через глобальный хук Molly.install\_global\_hook(). mlMolly (Maniacal Molly) перед запуском функции проверяет исходник через ast-парсер и ищет опечатки в именах переменных, функций, классов и импортов. MollyWaff (Molly with affection) — это интерактивный автофикс. Когда происходит ошибка, он анализирует её и предлагает пользователю интерактивное меню с вариантами (создать файл, установить модуль, заменить опечатку). GuMolly (Molly Guard) — журналирование, мягкая остановка и чекпоинты. Логирует ошибки в папку \~/.pymolly/all\_logs, ставит флаг при критических ошибках и позволяет сохранять состояние программы.



Все модули используют общий слой charm\_enhance, который мягко интегрируется с CharmPkk. Если CharmPkk установлен, Молли печатает сообщения через CharmPkk console: красивые рамки, цветной текст, интерактивные меню со стрелками. Если CharmPkk не установлен, всё работает на чистом print с ASCII-рамками. Зависимостей нет, только стандартная библиотека Python. Установка: pip install pymolly. Опционально: pip install "pymolly\[charm]" для красочного интерфейса. Связь с автором: reception.mailspypi@gmail.com.
